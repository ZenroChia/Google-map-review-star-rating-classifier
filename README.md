# Google Maps Review Star Rating Classifier

Project repository for a multi-class text classification project on Google Maps user reviews. The notebook explores the end-to-end pipeline for predicting star ratings from review text, including exploratory analysis, preprocessing, baseline machine learning, and deep learning experiments.

## Repository Contents

- [Google_Maps_Review_Star_Rating_Classifier.ipynb](Google_Maps_Review_Star_Rating_Classifier.ipynb)
- This README

## Project Summary

The project investigates how well different text representation and modelling strategies can predict ratings from 1 to 5 stars using review text only. It compares a classical Naive Bayes baseline against sequence-based models such as LSTM, and also includes transformer-oriented preprocessing for later experimentation.

## Kaggle Competition

This project was also submitted to a private Kaggle competition for the same Google Maps review classification task, involving Heriot-Watt Malaysia and Dubai teams across both undergraduate and postgraduate groups. All teams competed to submit the best-performing model predictions on an unknown test set, and our best-performing model prediction submission finished 3rd place overall on the final leaderboard and 1st place among the Malaysia teams.
